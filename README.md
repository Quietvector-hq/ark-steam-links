# ARK Steam Links

GitHub Pages用の中継ページです。

## 公開方法

1. GitHubで新しいリポジトリを作成します（例: `ark-steam-links`）。
2. このフォルダの `index.html` をリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branch を `main`、Folder を `/(root)` にして保存します。
6. Pagesの公開URLが表示されたら、そのURLに `?app=AppID` を付けてDiscordへ貼ります。

## 動作

Discord → GitHub Pages (HTTPS) → steam://store/AppID → Steamクライアント

ブラウザの設定によってはSteam起動確認が表示されたり、自動起動が拒否されることがあります。
その場合はページ内の「Steamで開く」ボタンを使用できます。
